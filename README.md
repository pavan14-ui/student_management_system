Project Overview: A Full Stack Student Management System developed to manage student information efficiently.

Frontend: HTML, CSS, and JavaScript are used to create a simple and user-friendly interface.

Backend: Python and FastAPI handle application logic and API requests.

Database: Microsoft SQL Server stores and manages student records.

Database Connection: Python connects to SQL Server using the pyodbc library.

Student Records: The system supports adding, viewing, updating, and managing student details.

Academic Management: It manages subject marks, total marks, percentages, grades, and rankings.

Statistics: The system provides student performance statistics and academic summaries.

Installation and Execution: Install the required dependencies using pip install -r requirements.txt and start the backend using python -m uvicorn api:app --reload.

Conclusion: This project demonstrates full-stack development, database connectivity, API integration, and student performance management.
